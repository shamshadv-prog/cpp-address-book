# C++ Console-Based Address Book Application

A lightweight, console-based information management software designed for rapid data manipulation and record indexing.

##  Key Features
* **Full CRUD Operations:** Create, Read, Update, and Delete address records using native C++ Standard Template Library (STL) containers.
* **Optimized Search Indexing:** Fast query processing for localized search formats.
* **Persistent Storage:** File I/O operations to save and reload records without data corruption.

##  Built With
* **Language:** C++ (C++17)
* **Tools:** GCC, GDB, Linux Terminal
